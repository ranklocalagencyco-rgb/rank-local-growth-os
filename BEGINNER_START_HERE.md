# Rank Local Growth OS — Beginner Start Here

You do not need to know how to code. Your job is to be the product owner.

## Create these accounts first
1. GitHub — code and version history.
2. Supabase — database and authentication.
3. Vercel — app hosting.
4. OpenRouter — Qwen/cheap AI access.

Do not worry about Google Places, Gmail or Hermes yet. We add those when we reach those milestones.

## Use a cloud workflow
Because your computer is weak, keep the project in GitHub and use a cloud coding environment/coding agent. Your computer mainly needs a browser.

## Create the repository
Create a **private** GitHub repository named:

`rank-local-growth-os`

Upload this starter pack into it.

Never upload API keys, passwords or `.env` files.

## Your first build target
Do not ask an AI to build the whole product.

First build only:
- Next.js + TypeScript app
- Supabase/Postgres connection
- authentication shell
- environment validation
- background job foundation
- logging
- dashboard shell
- SEND_MODE safety switch

Then test it before moving on.

## Golden rule
When an AI coding agent says a ticket is finished, require it to:
- run tests
- run typecheck
- run lint
- list every changed file
- explain remaining errors

Do not accept “it should work”.
